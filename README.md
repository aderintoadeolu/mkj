## 🚀 Key Features

1. **Dual-Hub Architecture:**
   - 📱 **Gadgets & Laptops:** iPhones (iPhone 11 through 15 Pro Max), MacBooks (M1/M2/M3 Silicon), Dell XPS, HP Spectre, and genuine accessories.
   - 🚗 **Auto Lounge & Motors:** Foreign-Used (Direct Tokunbo) vehicles including Lexus RX 350, Mercedes-Benz C300 AMG, Toyota Camry XSE "Spider", and Toyota Corolla with full Lagos Customs clearance details.
2. **Interactive Swap & Trade-In Estimator:**
   - Customers can trade in their existing device or car (condition, battery health, mileage).
   - Generates an estimated valuation and difference top-up.
   - Formats a pre-filled swap inquiry message sent straight to MKJ on WhatsApp.
3. **Instant WhatsApp Order Integration:**
   - Every product card, modal, and cart generates formatted WhatsApp messages directly to `+2348169315126`.
4. **Live Filter & Search:**
   - Real-time search across product name, specifications, and descriptions.
   - Category filters (Smartphones, Laptops, Cars, Audio/Accessories).
   - Condition filters (Brand New Sealed, Clean UK Used, Direct Tokunbo).
   - Sorting by featured, price (low-high, high-low), and ratings.
5. **Multi-Currency Support:**
   - Toggle seamlessly between Nigerian Naira (₦ NGN) and US Dollars ($ USD).
6. **Multi-Item Cart Drawer:**
   - Add multiple items to the cart and submit an itemized multi-product order directly via WhatsApp.
7. **Physical Store Locator & Directions:**
   - Clear landmark directions for students and visitors at Under G, Ogbomoso.
   - Direct Google Maps navigation link and one-click address copy.

## 💻 How to Run Locally

```bash
# 1. Navigate to the project directory
cd "C:\Users\User\.gemini\antigravity\scratch\mkj-enterprises"

# 2. Start the local development server
npm run dev

# The app will be accessible at:
http://localhost:3000/
```

### Build for Production Deployment
```bash
npm run build
```
The optimized static bundle will be generated in the `dist/` directory, ready to deploy to Netlify, Vercel, Firebase Hosting, Cloudflare Pages, or cPanel.
